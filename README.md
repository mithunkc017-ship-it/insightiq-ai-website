# InsightIQ AI STUDIOS — Enterprise AI Agency Website

Official repository for the **InsightIQ AI** web platform — an Apple & HackCulture inspired, clean, minimalist, and modern AI Agency website built to showcase and sell high-ticket AI services to businesses:
- **AI Websites & Intelligent Web Applications** (Generative UI, 3D stores, vector search)
- **Autonomous Multi-Agent Workforces** (Tool calling, reasoning loops, 24/7 background automation)
- **Enterprise Conversational AI & Voice Agents** (Sub-300ms latency, custom RAG, omnichannel)
- **Workflow & Document Intelligence** (Automated PDF/contract parsing, CRM & ERP routing)
- **Proprietary LLM Fine-Tuning & Private Models** (Air-gapped on-prem/cloud models, data sovereignty)
- **AI Readiness, Security & Architecture Audits**

---

## ⚡ 3D Robot & Spline Integration in the Hero Section

This website features an interactive **NexBot 3D Robot** concept from Spline:
- Embedded in [`src/components/HeroSplineContainer.jsx`](src/components/HeroSplineContainer.jsx)
- 50/50 split landing page layout in [`src/components/Hero.jsx`](src/components/Hero.jsx)
- Native `@splinetool/react-spline` and `@splinetool/runtime` installed
- Built-in interactive WebGL fallback Neural Core

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 + High-contrast Sky Blue & White theme
- **UI & Animations**: shadcn/ui components (`testimonials-6`, `avatar`, `infinite-slider`)
- **Icons**: Lucide React
- **3D Graphics**: Spline 3D + HTML5 Canvas WebGL
